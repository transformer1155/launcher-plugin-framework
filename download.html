三步上手Up and Running in Three Steps

1

下载并运行Download & Run

点击上方绿色按钮下载 AetherLauncher.exe，放到任意目录双击运行。单文件、免安装、不写注册表；数据目录默认在 exe 旁的 data/（便携模式）。 Click the green button above to get AetherLauncher.exe, drop it anywhere and double-click. Single file, no installer, no registry; the data dir defaults to data/ next to the exe (portable mode).

2

确认 MCP Server 在线Confirm the MCP Server Is Up

启动器启动时自动拉起 MCP Server（The launcher auto-starts its MCP Server on 127.0.0.1:3721 ）。一条命令验证：. One command to verify:

bash
curl http://127.0.0.1:3721/mcp -X POST -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
3

接入 Claude / CursorConnect Claude / Cursor

把 Aether 的地址填进客户端的 MCP 配置即可让 AI 控制启动器。完整报文示例与插件开发指南见Point the client's MCP config at Aether and the AI can drive the launcher. Full message examples and the plugin guide live in 文档 §4 MCP 协议接入Docs §4 MCP Protocol。

json
{
  "mcpServers": {
    "aether-launcher": { "url": "http://127.0.0.1:3721/mcp" }
  }
}
