## 需要记住的项目约定

- 即时模式：`App::theme` 是唯一真相源，消息循环不得跨帧缓存 `Theme`；外观改动下一帧生效。
- 右键菜单命中结果在 `Ui::finish()` 产生，只能下一帧用 `take_menu_click()` 消费，
  取完即清空；下标包含分隔线（实例菜单 `[0,1,分隔线2,3]`）。
- `Event::Wheel.delta` 由后端归一化成 ±1，`-1` 表示向下滚；UI 层按 48px/notch 换算。
- 仓库根目录不是 git 工作树（`git status` 报 `not a git repository`），改动靠文件级比对。
- 软件后端截图无 CJK 点阵，中文方块是预期；窗口圆角透明像素在 PNG/PPM 里用桌面底色填充，
  真实窗口靠 `CreateRoundRectRgn` + `SetWindowRgn`。
- UI 仍只写本地 `DataStore`，未接真实插件工具；启动游戏是 simulated（`pid=null`）。

## 修复闪烁 / 交互失效 / XP 风标题栏（同日第二轮）

- 用户反馈：UI 持续闪烁、控件完全点不动、窗口标题栏像 XP 时代。
- **交互失效根因**：`ui-core/src/ui.rs::detect_click` 对 `Event::MouseUp` 无条件
  `consumed[i] = true`，第一个调用控件检测的按钮（顶栏「外观设置」）吞掉所有抬起事件，
  后面的控件永远收不到点击；单控件测试测不出。改为先用只读
  `PressTracker::is_pressed(id)` 认领、再 `end(id)` 收尾，拖出取消语义保持不变。
- **闪烁是两个叠加根因**：① GDI 直绘到屏幕 DC（清屏→逐条画）+ `WM_ERASEBKGND`
  系统白画刷；② 输入框光标是两段接力的循环动画，失焦后轨道没停 →
  `any_animating()` 永真 → 16ms 心跳永不关 → 无动画需求时仍全屏重绘。
  修复：`WM_PAINT` 改内存 DC 双缓冲 + 单次 `BitBlt`，`WM_ERASEBKGND` 返回 1，
  窗口类不注册背景画刷；`text_input` 失焦时 `anim_stop(Slot::Caret)`；
  `run_loop` 每帧标脏后 `UpdateWindow`，避免 `WM_PAINT` 被心跳消息挤到队尾。
- **XP 风标题栏根因**：`WS_OVERLAPPEDWINDOW` 系统标题栏 + `SetWindowRgn` 让 DWM
  回退经典装饰。改为 `WS_POPUP | WS_MINIMIZEBOX | WS_MAXIMIZEBOX` +
  `WS_EX_APPWINDOW` 无边框窗口，顶栏自绘标题栏（`— □ ✕` + 空白处拖动）。
- 新增 `ui-core::WindowAction`（Drag/Minimize/ToggleMaximize/Close）+ `FrameState`
  共享槽 + `Ui::title_bar` / `request_window_action`；主循环 `state.take_window_action()`
  → `ui_backend_win32::perform_window_action()`（`ReleaseCapture` +
  `WM_NCLBUTTONDOWN/HTCAPTION`、`ShowWindow`、`PostMessageW(WM_CLOSE)`）。
- Win32 交互补强：`SetFocus(hwnd)`（popup 否则无键盘输入）、`TrackMouseEvent(TME_LEAVE)`
  → `Event::MouseLeave`、`WM_CLOSE` → `DestroyWindow`、圆角 region 改用 `GetWindowRect`
  并在 `IsZoomed` 时取消裁角。
- 软件后端给 `— □ ✕` 补内置 5×7 点阵（`caption_glyph`），离屏截图不再是方块。
- 新增 6 条测试（多控件抬起分派、拖出取消、标题栏拖动、窗口动作只消费一次、
  真实 App 布局端到端点关闭按钮、标题栏图标点阵）。验证：fmt/clippy 干净、
  `cargo test --workspace` 145 passed / 1 ignored、release 构建通过、
  `--win-selftest` 真实无边框窗口 1100×720 渲染 8 帧 + 截图成功。
- 交付更新：`dist/MinecraftLauncher.exe` 949,402 字节；四张软件截图与
  `ui-win32-shot.png` 重新生成；`dist/README.md` 增补 2.6/2.7、双缓冲、闪烁两层根因、
  无边框限制（不能拖拽边缘缩放）与新测试数。
